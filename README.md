# 🚗 Insurance Claims Estimation and Fraud Detection using EHOA-VGG19

This project presents an optimized deep learning framework for **insurance claim estimation and fraud detection** using **VGG19**, the **Enhanced Hippopotamus Optimization Algorithm (EHOA)**, and **Monte Carlo Dropout** for uncertainty-aware prediction.

The proposed system focuses on improving:
- ✅ Model Performance
- ✅ Convergence Speed
- ✅ Hyperparameter Optimization
- ✅ Prediction Reliability
- ✅ Real-Time Fraud Detection

---

# 🔥 Features

- Deep learning–based car damage classification using **VGG19**
- Hyperparameter optimization using **EHOA**
- Hybrid training strategy with fine-tuning
- Monte Carlo Dropout for:
  - Confidence score estimation
  - Uncertainty analysis
  - Claim severity prediction
- Manual review flagging for high-risk claims
- Real-time insurance claim analysis workflow

---
